# 地图编辑与资源目录

## 编辑和运行地图

地图保存在 `maps/`，使用 UTF-8 JSON，尺寸为 1200 × 780。游戏启动后会显示地图选择菜单，自动列出该目录中的所有 JSON 地图；使用上下键或鼠标选择，再按 Enter 或点击“开始游戏”。地图必须包含玩家和敌方各至少一个基地；河流、桥梁、山地、矿点、建筑和单位的位置都由地图文件指定。

在项目根目录运行：

```powershell
.\venv\Scripts\python.exe -m tools.map_editor
```

编辑器会打开默认战场。也可以打开 `maps/` 中的其他文件：

```powershell
.\venv\Scripts\python.exe -m tools.map_editor --map my_map.json
```

数字键 `1`–`9` 选择河流、桥梁、山地、矿点、基地、挖掘机、坦克、装甲工厂和防御塔；`Tab` 切换新单位或建筑的阵营。左键放置，右键删除，`[` / `]` 调整当前地形尺寸，`Ctrl+S` 保存当前地图，`F2` 或 `Ctrl+Shift+S` 输入文件名并另存一张地图，`Ctrl+N` 新建空白战场，`Esc` 退出。新地图保存到 `maps/` 后会自动出现在游戏的地图选择菜单。保存前会检查地图格式和两方基地；无效地图不会写入磁盘。

需要跳过地图选择菜单时，也可以从命令行明确指定地图：

```powershell
.\venv\Scripts\python.exe Attack.py --map maps/my_map.json
```

## `assets/` 的用途

`assets/` 用于**可选的美术与音效文件**，例如自制 PNG 单位/地形图、OGG 音效和 WAV 音效；地图数据应继续放在 `maps/`。当前渲染器使用程序绘图，音效由代码合成，所以空的 `assets/` 不会妨碍运行，也无需下载外部资源。后续接入素材时应保留程序绘图和合成音效作为缺省方案。
